# Review 01 · Architecture and roadmap nitpick

Scope: a line-by-line adversarial pass over `BASELINE.md`, `THREAT-MODEL.md`, `CONVENTIONS.md`, `AGENTS.md`, every milestone file, every register, the accepted decisions, the validator's rules and all 217 V0 tasks, plus keyword sweeps over the remaining 2,050 tasks for subjects the baseline names or an operating system needs. The question asked of every line was: what is missing, what contradicts something else, and what would let a false claim of progress through.

Severity: **blocker** stops a milestone from ever completing or lets false progress land; **defect** is a wrong or contradictory statement; **gap** is missing work or a missing threat; **note** is recorded and deliberately left alone.

## 3. Threat model line-by-line

- §2 adversary table lacked a row for rogue input and storage peripherals and did not count Wasm guests as compromised Components or AT clients as over-reaching automation. Rows added.
- §4 safety layers: language safety now states that a kernel panic is still a crash (I-101); component isolation names unzeroed page reuse; trusted surfaces name device-injected input; a mount-policy layer names T-044.
- §5 blast radius now lists the Wasm runtime and the filesystem mounter among the untrusted-input classes needing the same analysis.
- T-037 was registered but cited by nothing; now cited by KRN-038.

## 4. V0 task pass

Every V0 task was read in full. Beyond the items above, the tasks are consistent: criteria are observable, verification lines name harnesses and matrix entries, and every gate criterion that names a scale ("at the scale recorded in the verifying task") resolves to a concrete number inside exactly one task. Duplications noted and left alone: HW-001, BOOT-002 and LAB-003 all touch the first boot of H-002 (racking, booting and recording posture are separable); CAP-001 and OBS-002 both describe capability audit events (emission versus exposure).

## 5. What did not change

- D-0031's swapped option labels (accepted decisions are immutable; recorded in 1.8).
- BEN-007 stays done; its over-ticked criterion is answered by BEN-064.
- The 16-task V0 critical path beyond the IPC-017 fix.
- Gate kinds for publish-only benchmark series.
- Direct pushes by the sole maintainer.
