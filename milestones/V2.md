# V2 — Desktop preview
- Sequence: 4
- Title: Desktop preview
- Baseline: §62
- Hardware scope: H-001, H-002, H-004, H-005
- Surfaces to freeze: S-019
- Risks to retire: R-035, R-036, R-037, R-038, R-039, R-040, R-041, R-042, R-043, R-044, R-045, R-068, R-070, R-078, R-084

## Purpose

Deliver a polished desktop with laptops, multi-monitor, HDR, VRR, Bluetooth, Windows applications and a gaming proof-of-concept, rollback and snapshots, a native repository, and semantic automation, on three deliberately constrained target machines. The component manifest (S-019) freezes; the UI protocol (S-015) and package manifest (S-018) are freeze candidates whose Layer 2 lock happens at V4. Semantic registry, then automation rules, then the AI-broker demo, in that order. NVIDIA (H-006) is tracked as experimental with no gate.

## Not in this milestone

Installer for the general public (still image-based install with a guided script). Crash reporting pipeline and hardware compatibility database as products. Public package submission process. Kernel-level anti-cheat games. NVIDIA as a gated target. Distributed or remote interfaces. Native filesystem. Certification of accessibility compliance. Any Layer 1 freeze.
