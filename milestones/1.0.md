# 1.0 — Public stable
- Sequence: 7
- Title: Public stable
- Baseline: §54, §70
- Hardware scope: H-001, H-002, H-003, H-004, H-005, H-006, H-007, H-008, H-009, H-010, H-011, H-012, H-013, H-014, H-015, H-016, H-017
- Surfaces to freeze: none
- Risks to retire: R-061, R-062, R-063, R-064, R-065, R-066

## Purpose

Declare the first supported release: frozen Layer 1 ABI, published support window and security SLA, tiered hardware compatibility, measured compatibility coverage, guaranteed atomic update and rollback, and complete documentation, with every claim backed by a published measurement. Layer 1 is already frozen at V4; this rung amends the freeze decision to stable for 1.x and turns support commitments on. No new Layer 1 surface is frozen here.

## Not in this milestone

Any feature not already complete at V4 feature freeze. ARM64 or RISC-V. Kernel anti-cheat, vendor DRM. Native filesystem, native GPU stack, native browser, native IDE. Distributed or remote interfaces. Hardware capability enforcement (CHERI-class); only ABI room is preserved. Performance superiority claims not backed by published measurements. Universal PC compatibility.
