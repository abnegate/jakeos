# V0.5 — Application model
- Sequence: 2
- Title: Application model
- Baseline: §60
- Hardware scope: H-001, H-002, H-003
- Surfaces to freeze: none
- Risks to retire: R-015, R-016, R-017, R-018, R-019, R-020, R-021, R-022, R-023, R-024, R-071, R-072, R-076, R-081

## Purpose

Prove that real applications can be built on the native model: a compositor, windows, input, declarative UI, immutable packages, capability-based file selection, service restart and simple system generations. Native init replaces the retained initramfs path. Four native applications and one Wayland Linux application run from immutable packages. Accessibility metadata is emitted from day one. Laptop procurement, the input-to-photon rig, reserved signing fields and the grant-taxonomy decision land so later rungs are not waiting on them.

## Not in this milestone

Multi-monitor, HDR, VRR, fractional scaling, multi-GPU. Audio. Networking beyond wired Ethernet passthrough. Wi-Fi, Bluetooth, suspend/resume, battery as gates (H-004 may be used exploratorily). Windows personality. Native package repository or store; packages are installed from local files. Browser, IDE or Git as native applications. Semantic interfaces beyond what the four apps need. Screen sharing and remote surfaces. Full system history and restore of user data. Any Layer 1 freeze.

## Gates

### V0.5-G01 · Native compositor presents on the reference GPU
- Kind: functional
- Verified by: GFX-010, GFX-008, GFX-006, GFX-029, GFX-041
The compositor starts from a system generation, drives the H-002 GPU via DRM/KMS with GPU-accelerated composition, and presents at the display's fixed refresh. Zero dropped frames over the idle-desktop capture named in the verifying task. H-003 covers the same path in CI.

### V0.5-G02 · Native application window, input and declarative UI
- Kind: functional
- Verified by: UIP-026, SDK-023, UIP-012, UIP-010
A native application opens a window, receives keyboard and mouse input, renders declarative UI and animates at the display refresh rate. Frame-time is measured by B-018; this gate is the functional path.

### V0.5-G03 · Compositor crash recovery rebinds every window
- Kind: functional
- Verified by: GFX-007, GFX-009, GFX-039, SVC-002
Killing the compositor restarts it and rebinds all open windows with no application exit, verified the number of consecutive times named in the verifying task on H-003 and on H-002. Supervision semantics (restart budgets, rebind protocol, readiness) are in place.

### V0.5-G04 · Immutable packages and coexisting versions
- Kind: functional
- Verified by: PKG-025, STO-032, PKG-032, PKG-042, STO-008, PKG-029, PKG-024, MEM-016, CMP-029
Installing a package adds it to the content-addressed store without writing outside the store, verified by filesystem diff. Two versions of the same library coexist and are used by two different installed applications simultaneously; identical content is deduplicated. Signature, signer and trust-policy fields are reserved in the manifest.

### V0.5-G05 · System generations switch and roll back at the boot menu
- Kind: functional
- Verified by: PKG-016, BOOT-014, PKG-015
An update produces a new generation. Selecting the previous one at the boot menu restores the previous kernel, compositor and packages, verified by an automated boot-menu test.

### V0.5-G06 · File chooser returns UserSelected and nothing else
- Kind: functional
- Verified by: STO-034, STO-007, APP-002, SDK-017, GFX-040, OBS-024
The Image Viewer starts with UI and GPU capabilities only, opens a user-chosen image via `UserSelected<Image>`, and a test confirms it cannot enumerate or open any other file in the same directory. The chooser is trusted UI (T-012).

### V0.5-G07 · Clipboard is a capability
- Kind: functional
- Verified by: UIP-003, UIP-014, UIP-026
An application without the clipboard capability cannot read clipboard contents. The denial is tested. X11 primary selection does not cross into this surface.

### V0.5-G08 · Four native applications pass scripted scenarios
- Kind: functional
- Verified by: APP-004, APP-006, APP-003, APP-005
Terminal, File Browser, Text Editor and Image Viewer each pass their scripted acceptance scenarios and are dogfooded by the core team for the session count named in the verifying task.
