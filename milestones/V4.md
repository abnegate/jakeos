## Purpose

Freeze the Layer 1 ABI, complete every 1.0 feature, widen hardware, harden security through external audit, and demonstrate release-quality stability on a real beta fleet so that 1.0 is a declaration rather than a scramble. Every Layer 1 surface (S-001 through S-012) freezes with a conformance suite. Layer 2 interface versions for 1.x are enumerated and locked. Tier 1 is at least the twelve named machines in Hardware scope. x86-64 only; ARM64 explicitly out.

## Not in this milestone

New features after the first release candidate. New Layer 1 ABI entry points. ARM64 or RISC-V ports. Native filesystem or object store. Native GPU driver rewrites. Distributed interfaces. Kernel anti-cheat support. Enterprise management features.
