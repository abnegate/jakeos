## Milestone ladder (to `milestones/*.md`)

Each file: Sequence, Baseline §, Hardware scope (H-IDs), Surfaces to freeze, Risks to retire, Purpose, Not in this milestone, `## Gates` (`V0-G01 · …`, Kind functional|benchmark|compatibility|demo|process, `Verified by:` task IDs, `Benchmark: B-…` or `Corpus: C-…`, optional `Or: <adr task>` for conditional gates), `## Demos`, Notes, generated block. Content from the design pass, with the critique's corrections applied:

- **V0 Execution model** — QEMU + one AMD reference desktop; native components started from a retained initramfs; component/task/capability/channel/operation/MemoryObject/ResourceDomain/tracing proven with L1 negotiation handshake test; L0 Linux corpus zero regressions; all benchmarks *publish-only* (no V0 numeric targets); explicit spikes for every L1 surface; threat model; Windows scoping adr. Target ~180–220 tasks after collapsing constraints and "retain X" items.
- **V0.5 Application model** — compositor with crash-rebind (SVC supervision), declarative UI with a11y metadata, immutable packages with reserved signing fields, generations with boot rollback, native init, UserSelected chooser, clipboard capability, four apps, one Wayland app; L1 corpus; image builder; laptop procurement and input-to-photon rig; a11y tree and grant-taxonomy adrs.
- **V1 Developer preview** — self-hosting, daily-driving, SDK v1 (L1 freeze candidates, L2 evolution rules frozen), `os env`, Wi-Fi/audio/suspend on Intel laptop, GPU-accelerated Linux browser/IDE (seccomp, userns, overlayfs, ptrace, inotify, 32-bit in place), signed repo, debugger, profiler, IDL→docs, upstream rebase; Wine bring-up non-gated; L2 corpus.
- **V2 Desktop preview** — three target machines; multi-monitor/HDR/VRR/Bluetooth/500-cycle suspend; Windows personality W1 gates; permissions UI; screen-share capability; snapshots UI; store client; automation rules then AI demo; screen-reader prototype; ComputeDevice demo; safe-mode session; L3 corpus.
- **V3 Public alpha** — installer with FDE + Secure Boot on six Tier 1 machines; updater with auto-rollback; opt-in crash reporting; HCL; public repo with third-party packages; security response exercised; continuous fuzzing; multi-user; 100% L1 reference docs; L4 + W2.
- **V4 Beta** — L1 frozen with conformance suite; L2 versions locked; feature freeze; external audit closed; ≥ 2,000-machine fleet ≥ 99.5% crash-free; V3→V4 upgrades; ≥ 10 Tier 1 machines; a11y script 100%; 10 languages; reproducible builds; L5 + W3.
- **1.0 Public stable** — 30-day soak zero P0/P1; ABI stability statement; 24-month support and 14-day CVE SLA published and met; update/rollback guarantee; every §54 metric published vs Linux/Windows/macOS; docs complete; 1.x branch + 2.0 RFC. Explicit non-promises listed.
- **LATER** — parking rung (casting, NFC, WWAN, MIDI, ARM64, native FS/GPU stack, distributed interfaces).
