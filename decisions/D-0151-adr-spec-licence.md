## Context
Layer 2 Interface definitions first appear in V0.5, so the IDL and ABI specification licence must be settled before third parties see them (§14, §66).

## Options

### Option A · Permissive specification license plus royalty-free patent non-assert
Summary: A specification license with an explicit patent non-assert.
Consequences: Reimplementable without legal exposure; a separate license to maintain.
Evidence: none

### Option B · Layer 2 userspace license with no extra patent grant
Summary: The userspace code license covers the specification.
Consequences: One license everywhere; no explicit patent protection for reimplementers.
Evidence: none

### Option C · CC0-class dedication
Summary: The specification is public domain.
Consequences: No friction; no patent clause.
Evidence: none
