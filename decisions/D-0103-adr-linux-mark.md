## Context
Linux is a registered trademark, so whether it appears in product naming must be settled before public-alpha marketing (§1, §3).

## Options

### Option A · LMI sublicense and use Linux in naming
Summary: Obtain a sublicense and use the mark.
Consequences: Recognisable positioning; ongoing sublicense obligations.
Evidence: none

### Option B · Forbid Linux in product naming
Summary: Never use the mark in names or marketing.
Consequences: No obligations; the kernel heritage is less visible.
Evidence: none
