## Context
Whether the Personality userland is built from source or redistributes a distribution's binaries must be decided with trademark and licence obligations (§50, §56.3).

## Options

### Option A · Source-built userland
Summary: glibc, Mesa and coreutils are built from source.
Consequences: Full control and reproducibility; build effort.
Evidence: none

### Option B · Redistribute a named distribution's binaries
Summary: A distribution's binaries are redistributed.
Consequences: Fast; trademark and source-offer duties.
Evidence: none

### Option C · Hybrid with a named boundary
Summary: Some built, some redistributed.
Consequences: Balance; a boundary to define.
Evidence: none
