## Context
Redistribution licensing and wrapper ownership for third-party Linux and Windows software need a legal policy separate from PKG mechanics (§3, §28, §49).

## Options

### Option A · Project-owned wrappers with redistributable licenses
Summary: The project owns wrapper metadata under a redistributable license.
Consequences: Clear provenance; the project is responsible for wrapper correctness.
Evidence: none

### Option B · Publisher-owned wrappers
Summary: Publishers own and license their wrappers.
Consequences: Responsibility sits with the publisher; quality varies.
Evidence: none

### Option C · No official repackaging
Summary: The project ships no wrappers.
Consequences: No liability; users assemble their own.
Evidence: none
