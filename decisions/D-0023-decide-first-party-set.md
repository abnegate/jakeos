## Context
Which first-party applications are native Components versus bundled personality applications at 1.0 must be decided so the native subset stays splittable into one task per application (§56.5, §60, §62, §63).

## Options

### Option A · All native
Summary: Every listed application is a native Component.
Consequences: Consistent platform showcase; multi-month commitment per application.
Evidence: none

### Option B · All bundled compat
Summary: Every listed application is a bundled personality application.
Consequences: Fastest path to a complete desktop; the native platform has no first-party proof beyond the demo apps.
Evidence: none

### Option C · Mixed set
Summary: A per-application table names which are native and which are bundled.
Consequences: Effort goes where the native model matters most; the table must be maintained and explained.
Evidence: none
