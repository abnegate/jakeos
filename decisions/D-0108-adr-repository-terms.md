## Context
The public-alpha repository is an intermediary needing a developer agreement, content policy, malware removal and DMCA terms (§28, §63).

## Options

### Option A · Curated store with a signed developer agreement
Summary: Publishers sign an agreement and the project curates content.
Consequences: Clear responsibilities and takedown authority; onboarding friction for publishers.
Evidence: none

### Option B · Open repository with notice-and-takedown
Summary: Anyone may publish and content is removed on notice.
Consequences: Low friction and fast growth; moderation is reactive and the project carries intermediary duties.
Evidence: none

### Option C · Third-party repos only
Summary: The project hosts no third-party Packages.
Consequences: No intermediary liability; no first-party channel for users.
Evidence: none
