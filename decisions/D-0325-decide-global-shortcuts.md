## Context
Global shortcuts need a model without raw key grabs, which are a keylogger primitive (§9, §41, T-012).

## Options

### Option A · Named actions bound in Settings, no raw grabs
Summary: Named actions.
Consequences: Safe; user setup.
Evidence: none

### Option B · Compositor-reserved media and screenshot keys only
Summary: Reserved keys only.
Consequences: Minimal; no app shortcuts.
Evidence: none

### Option C · X11-style global key grabs
Summary: Raw grabs.
Consequences: Familiar; rejected per T-012.
Evidence: none
