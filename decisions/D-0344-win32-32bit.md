# D-0344 · Decide 32-bit Win32 support and WoW64 requirements

## Context
Whether 32-bit Win32 binaries run in 1.0 (Q-040) decides the honest membership of the W corpora (C-007): most older titles and many installers are 32-bit (§48, §56.2). Kernel ia32 retention is LNX-015's half; this decision is the Win32 and WoW64 half and states what kernel support it assumes. The maintainer's recorded direction is option A, for the adr to confirm.

## Options

### Option A · 32-bit Win32 in 1.0
Summary: 32-bit Win32 is supported in 1.0 through Wine's WoW64 mode, assuming LNX-015 retains ia32 in the kernel and H-016 runs it in CI.
Consequences: The Steam back catalogue and legacy installers are in scope and the W corpora can include them. WoW64 in Wine is newer than its classic 32-bit build, so W1 to W3 must test both paths, and the personality ships 32-bit multilib (LNX-086).
Evidence: none

### Option B · 64-bit-only
Summary: 64-bit Win32 only.
Consequences: The simplest personality with one code path. Excludes most pre-2018 games and many installers from the corpora, which contradicts the owner's direction and the §56.2 goal.
Evidence: none

### Option C · 32-bit only via the VIRT fallback
Summary: 32-bit titles run only in the VIRT fallback VM.
Consequences: The host stays 64-bit only. Every 32-bit game gets VM graphics and input latency, which §56 says must not be visible; rejected for games.
Evidence: none

## Decision
Proposed. Not yet accepted.
