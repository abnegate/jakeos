## Context
Public alpha distributes disk encryption and TLS worldwide, so export-control classification and mirror obligations must be recorded (§51, §63).

## Options

### Option A · Open-source encryption exception with a filed notice
Summary: Use the publicly available encryption exception and file the notice.
Consequences: Standard path for open source; requires filing and record keeping.
Evidence: none

### Option B · Restrict distribution by jurisdiction
Summary: Block downloads from restricted jurisdictions.
Consequences: Avoids the question; mirrors and users route around it.
Evidence: none

### Option C · Mirrors independently obligated
Summary: Each mirror handles its own obligations.
Consequences: Project scope stays small; inconsistent compliance.
Evidence: none
