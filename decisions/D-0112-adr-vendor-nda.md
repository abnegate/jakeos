# D-0112 · Decide vendor NDA policy for hardware documentation

## Context
Hardware enablement may use NDA documentation while the tree and public docs may not, so the policy must be recorded (§55, §57).

## Options

### Option A · Forbid NDA docs entirely
Summary: No contributor reads NDA material.
Consequences: No contamination risk; slower enablement for undocumented hardware.
Evidence: none

### Option B · Read but never reproduce
Summary: NDA documents may be read and nothing from them appears in the tree or public docs.
Consequences: Practical enablement; relies on contributor discipline and a review checklist.
Evidence: none

### Option C · Quoted excerpts under recorded conditions
Summary: Excerpts may appear with recorded vendor permission.
Consequences: Better public documentation; legal tracking per excerpt.
Evidence: none
