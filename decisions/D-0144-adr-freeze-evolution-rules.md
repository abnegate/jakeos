## Context
Layer 2 evolution rules freeze at V1 with SDK v1 after the V0 prototype and V0.5 UI protocol bump (§12, §66), or the freeze defers to V2.

## Options

### Option A · Freeze the V0 prototyped rules as S-014 at V1
Summary: The evolution rules freeze now with the spike and this Decision in the closure.
Consequences: SDK v1 has stable rules; less room to fix problems the UI protocol bump exposed.
Evidence: none

### Option B · Keep prototyped and freeze at V2
Summary: Freeze defers one rung.
Consequences: More real-world exercise; SDK v1 developers face uncertainty.
Evidence: none
