## Context
Whether xdg-desktop-portal is the bridge through which Linux apps reach native grants must be decided (§9.1, §25, §47).

## Options

### Option A · Portals as the sole grant bridge
Summary: Portals are the only way Linux apps get grants.
Consequences: Reuse of what apps already speak; portal coverage limits.
Evidence: none

### Option B · Second Personality-specific permission model
Summary: A new permission model.
Consequences: Tailored; duplication.
Evidence: none

### Option C · Ambient home access for Linux GUI apps
Summary: Linux apps get the home directory.
Consequences: Easy; rejected against I-035.
Evidence: none
